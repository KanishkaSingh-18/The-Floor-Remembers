# The Floor Remembers

A 2D puzzle-platformer developed using Godot Engine 4.

## About

The Floor Remembers is a puzzle game where your previous
movements are recorded and replayed through a ghost character.

Players cooperate with their past selves to solve puzzles,
activate pressure plates and unlock doors.

## Tech Stack

- Godot Engine 4
- GDScript
- 2D Game Development

## Planned Features

- Player movement and jumping
- Movement recording
- Ghost movement replay
- Interactive pressure plates
- Puzzle-based levels
